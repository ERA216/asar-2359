# Асар: 23:59 — один полный раунд

Простой локальный прототип: HTML + JavaScript. Vite запускает страницу;
бэкенда и базы данных нет. Код этого прототипа пока не создан через iDos AI Coder:
для подачи на сайдтрек необходимо выполнить отдельное требование использования iDos.

Есть один раунд на карте кампуса и отдельная проверка Memo в Solana Devnet.

## Правила раунда

Соберите три части проекта: **1 — текст, 2 — код, 3 — слайды**.
Чтобы подобрать часть, наступите на её клетку. Затем дойдите до принтера.
Запас — **21 ход**. Каждый переход на соседнюю свободную клетку тратит один ход;
попытка пройти через здание не тратит ход. Зажатая клавиша не расходует ходы повторно.
Принтер без всех трёх частей не завершает раунд.

Доставка полного проекта даёт победу, в том числе на последнем ходе.
Если ходы закончились раньше доставки — поражение. После окончания двигаться нельзя.
Кнопка «Начать заново» в любой момент возвращает игрока в общагу, все части на карту
и восстанавливает 21 ход. Memo и подключение кошелька от повтора раунда не меняются.
Короткий маршрут занимает 17 ходов, поэтому есть запас на четыре лишних шага.
Ориентир для первого знакомства — 1–2 минуты с обдумыванием маршрута;
реальную длительность ещё нужно проверить на игроках. Таймера пока нет.

## Запуск на Windows

Нужен Node.js 20.19+ или 22.12+.
Откройте PowerShell в папке проекта и выполните:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес `Local`, который появится в терминале (обычно http://localhost:5173).
Вы увидите карту кампуса. Двигайтесь стрелками, WASD или кнопками под картой.
Через здания пройти нельзя. Число 23:59 — название игры, таймера пока нет.
Чтобы остановить страницу, нажмите Ctrl+C в терминале.

## Телефон

Подключите телефон и компьютер к одному Wi-Fi. Откройте на телефоне адрес `Network`
из терминала Vite. Если Windows спросит о доступе к сети, разрешите только для частной сети.

Карта работает в обычном мобильном браузере. Для кошелька на телефоне нужен
встроенный браузер Phantom и опубликованный HTTPS-адрес страницы. Локальный HTTP-адрес
по Wi-Fi подходит для карты, но Phantom может не предоставлять на нём подключение.
Первую настоящую запись проще сделать на компьютере в браузере с расширением Phantom.

## Настоящая запись и чтение Memo

1. В Phantom включите тестовый режим и выберите Solana Devnet.
2. Нажмите «Подключить Phantom» и разрешите подключение.
3. Скопируйте публичный адрес кошелька. На https://faucet.solana.com/ запросите
   тестовые SOL для этого адреса в Devnet. Они нужны только для комиссии.
4. Оставьте готовый текст или введите свой. Memo публичный; секреты туда не вставляйте.
5. Нажмите «1. Проверить запись». Должны появиться успешная проверка и размер комиссии.
6. Нажмите «2. Подписать и записать», затем подтвердите транзакцию в Phantom.
7. Дождитесь сообщения о подтверждении и совпадении текста. Ниже появятся настоящий
   номер транзакции, ссылка на Explorer и текст, прочитанный из сети.
8. Скопируйте номер транзакции, обновите страницу, вставьте его обратно и нажмите
   «Прочитать из Devnet». Кошелёк для этого не нужен. Текст должен остаться тем же.

Ничего не отправляется автоматически при открытии страницы или движении игрока.
Программа Memo: `MemoSq4gqABAXKb96qnH8TysNcWxMyWCqXgDLGmfcHr`.
RPC фиксирован: `https://api.devnet.solana.com`. Используется транзакция v0 и
`@solana/web3.js` для прямой совместимости с Phantom без UI-фреймворка.
Подписанная транзакция отправляется самим приложением только в Devnet.
Чтение использует `getParsedTransaction`, проверяет успешное выполнение и адрес Memo.
Публичный RPC и faucet иногда ограничивают запросы: при ошибке подождите и повторите чтение.
Запись Memo подтверждает текст и подпись кошелька; она не доказывает прохождение игры.

Если страница уже показывает номер транзакции, сначала повторите **чтение**.
Повторная отправка создаст ещё одну запись. Сохраните номер: после обновления
страница не хранит его, браузерная база данных в проекте не используется.
