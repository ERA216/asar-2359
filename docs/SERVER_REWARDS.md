## Токен и серверная проверка

- ASAR существует в **Solana Mainnet**: mint `BHdDPbwbKW4XKsxhvi9zEbeWtEjWsvA9RFh9vZPLidos`, 6 decimals. Он прописан как `Currency.CryptoCurrencies.Main` в PROD iDos. В DEV iDos криптовалюта `Main` не настроена; отдельная Devnet-версия ASAR и её mint-адрес **не созданы/не известны**.
- **Локальный сервер-казна не создан**: нет процесса выплат, кошелька казны, приватного ключа и `.env` с ним. Есть только `server-reward-verifier.js` с проверкой серверной карты/маршрута и пределом 1/2, а также DEV Cloud Code ревизии 7 (`asarDevStart`/`asarDevFinish`). DEV-тест маршрута прошёл, но обработчик всегда возвращает `granted: false`; игра его не вызывает. В PROD Cloud Code для наград нет.
- Для реальных выплат ещё нет подтверждённого API обеспеченного начисления, проверки остатка пула ASAR и атомарной защиты от параллельных повторов. В PROD iDos вход с подписью кошелька выключен (`WalletLogin.Enabled=false`); вывод ограничен возрастом аккаунта 7 дней. Ни выдача ASAR, ни вывод в кошелёк не проверены.

## Сети — не путать

- `devnet-memo.js` задаёт `https://api.devnet.solana.com`; `memo.js` и `gift.js` используют **Devnet** для записок и помощи по ссылке. Подпись Phantom в этих функциях относится к Devnet-транзакциям. Само `provider.connect()` лишь даёт адрес и не является серверным доказательством владения для награды.
- **Mainnet** используется пока только для существующего mint ASAR в конфигурации PROD iDos и его read-only проверки через публичный RPC. Код игры не отправляет ASAR в Mainnet и не начисляет его.
- `KJ56QZ5E-DEV` — среда iDos для проверки Cloud Code, а не Solana Devnet; её маршрутный тест не переводит токены.
