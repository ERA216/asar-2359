# Asar — игра о студенческом дедлайне

Соберите текст, код и слайды, а затем доберитесь до принтера, пока не закончились ходы. **Asar** — браузерная пиксельная игра для iDos Games. Название отсылает к казахской традиции взаимопомощи — асару.

[Играть на iDos Games](https://idosgames.com/app/KJ56QZ5E/) · [Прямой адрес игры](https://kj56qz5e.idos.games/) · [GitHub Pages](https://era216.github.io/asar-2359/) · [English README](README.md)

## Возможности

- Генерируемые проходимые карты, ограничение ходов и патруль охранника с 21-го уровня.
- Три темы, повторяющиеся каждые 30 уровней: кампус (1–10), столовая (11–20), ночной кампус (21–30).
- Рынок с предметами и скинами, панель прогресса и обучение.
- Управление стрелками, WASD или экранными кнопками на телефоне; отдельная громкость музыки и эффектов.
- Необязательная помощь другу по ссылке через Solana.

## Solana: что работает сейчас

Играть можно без кошелька. Подключение Phantom открывает функции помощи и записи Memo в **Solana Devnet**; транзакции требуют тестовых SOL. Монеты рынка — **локальная игровая валюта, не токены ASAR**. Они доступны только при подключённом кошельке и хранятся в браузере отдельно для каждого адреса.

Mint ASAR существует в **Solana Mainnet**, но игра сейчас **не выдаёт и не переводит ASAR**. Экспериментальная серверная проверка прохождения описана в [SERVER_REWARDS.md](SERVER_REWARDS.md); действующей системой выплаты она не является. Не вводите секреты или seed-фразу в публичную запись Memo.

## Запуск и проверка

Нужен Node.js **20.19+** или **22.12+** и npm.

```sh
npm ci
npm run dev
```

Сборка: `npm run build` (результат в `dist/`). Локальные тесты: `npm test`. Отдельный `npm run test:cloudcode:dev` обращается к внешней DEV-среде iDos и не входит в локальный набор.

На компьютере используйте стрелки или WASD; на телефоне — экранные кнопки. Значок **?** повторно открывает обучение.

## Структура и публикация

`main.js` управляет раундом; `level-generator.js`, `level-solver.js` и `guard.js` отвечают за карты и патруль; `sidebar.js`, `market.js`, `inventory.js` — за интерфейс и предметы; `gift.js`, `memo.js`, `devnet-memo.js` — за функции Solana. Подробная история разработки находится в [PROJECT_NOTES.md](PROJECT_NOTES.md).

GitHub Pages собирается автоматически из `main` через [GitHub Actions](.github/workflows/deploy.yml). **Публикация в iDos Games выполняется отдельно**: отправка кода в GitHub сама по себе не обновляет игру. Title ID: `KJ56QZ5E`.
